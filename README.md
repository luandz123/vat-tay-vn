# VậtTay.vn

Nền tảng quản lý giải vật tay: tạo giải, đăng ký, thu phí VietQR, cân, bảng đấu và kết quả realtime.

- Kiến trúc & quy tắc: [`CLAUDE.md`](CLAUDE.md)
- Database: [`docs/database.md`](docs/database.md)
- Kế hoạch: [`docs/plan.md`](docs/plan.md)

```bash
cp .env.example .env.local   # điền thông tin Supabase
npm install
npm run db:migrate
npm run dev
```
